# 硬件故障诊断与深度排查速查字典 (Hardware Troubleshooting & Diagnostics)

本文档归纳整理了个人电脑在物理电气层、BIOS 自检阶段、系统运行期及高负载场景下的全流程诊断树与精准定位方法。

---

## 1. 开机上电与 POST 自检故障诊断树

```
按下电源按键：
  ├─ [没有任何反应]
  │    ├─ 1. 排查插座总控与电源开关（I/O 键是否打在 I 档）；
  │    ├─ 2. 拔下主板 Power SW 跳线，用螺丝刀金属头轻触两颗针脚，若正常开机说明机箱按键开关断线损坏；
  │    ├─ 3. “电源短接法”自测：拔出 24-Pin 主供电插头，使用回形针短接绿线（PS-ON）与任意黑线（GND），
  │    │     若电源风扇完全不转，判定电源内部保险丝烧断或继电器损坏。
  │    └─ 4. 主板防短路保护：机箱内部多装了铜柱短接主板背面，必须拆出主板做“离机最小化系统测试”。
  │
  ├─ [风扇狂转 / 循环重启 / 无法显示]
  │    └─ 观察主板 EZ Debug 故障指示灯：
  │         ├─ [CPU 灯亮]  ──> 8-Pin CPU 辅助供电漏接；CPU 插槽弯针；老 BIOS 不认新 CPU（需用 Flashback 盲刷）。
  │         ├─ [DRAM 灯亮] ──> 内存金手指微氧化；未插在 2/4 槽；内存时序无法通过训练；单条逐一插在 A2 槽排查。
  │         ├─ [VGA 灯亮]  ──> 显卡未插满物理卡扣；外接供电虚接；显示线误插在主板核显口；老老显示器 DP 握手失败。
  │         └─ [BOOT 灯亮] ──> 硬盘 EFI 引导文件损坏；硬盘无供电/掉盘；CSM 兼容模式关闭导致无法识别 MBR 系统盘。
```

## 2. 核心 Windows 蓝屏代码（BSOD）终极字典

| 蓝屏终止代码 (Stop Code) | 硬件/驱动底层诱因 | 极客级排查与修复流程 |
| :--- | :--- | :--- |
| **`0x00000124`**<br>`WHEA_UNCORRECTABLE_ERROR` | 硬件严重电气错误：CPU 瞬态供电不足、Intel 13/14代缩缸、NVMe 固态掉盘 | 1. 抓取 Minidump，使用 WinDbg 运行 `!analyze -v` 查看 `MCA_COD` 错误架构；<br>2. 若指向 CPU 内部寄存器，进入 BIOS 适度拉高核心电压或关闭超频；<br>3. Intel 13/14 代酷睿立即更新带 0x129/0x12B 微码的最新 BIOS。 |
| **`0x0000001A`**<br>`MEMORY_MANAGEMENT` | 内存硬件物理损坏、XMP/EXPO 超频不稳定、颗粒高温翻转 | 1. 立即进 BIOS 关闭 XMP/EXPO 恢复 4800MHz JEDEC 默频；<br>2. 运行 TestMem5（跑 anta777 配置）进行 3 轮压力测试；<br>3. 检查机箱内部积热，确保内存温度低于 50℃。 |
| **`0x0000000A`**<br>`DRIVER_IRQL_NOT_LESS_OR_EQUAL` | 底层硬件驱动试图访问受保护的高位内存地址 | 1. 查看蓝屏下方提示的具体 `.sys` 文件名；<br>2. 90% 发生于无线网卡、蓝牙或显卡驱动冲突，断网进安全模式用 DDU 清除重装。 |
| **`0x0000007A`**<br>`KERNEL_DATA_INPAGE_ERROR` | 系统核心页面文件从硬盘向内存载入时硬件超时 | 1. NVMe 固态硬盘触发过热保护强制掉盘，或 APST 休眠唤醒失败；<br>2. 重新拔插 M.2 固态，撕掉导热垫薄膜，加装金属马甲；<br>3. 在电源选项中关闭 PCI Express 链路状态节能。 |
| **`0x000000EF`**<br>`CRITICAL_PROCESS_DIED` | 关键系统服务（如 `csrss.exe` / `svchost.exe`）异常崩溃 | 多数因固态硬盘发生物理级闪退或系统盘系统文件严重受损；运行 `sfc /scannow` 与 `DISM` 修复，检查 SSD 健壮性。 |
| **`0x0000003B`**<br>`SYSTEM_SERVICE_EXCEPTION` | 常见图形子系统或系统调用越界 | 重点排查显卡驱动 `nvlddmkm.sys` 或特定外设驱动（如雷蛇/罗技灯控软件）。 |

## 3. 显卡崩溃与画面渲染故障排查

### 3.1 显卡掉驱动（TDR 机制与 4101 错误）
*   **现象**：画面冻结后黑屏闪烁，游戏闪退，事件查看器记录 `nvlddmkm 事件 ID 4101：显示器驱动程序已停止响应，并且已成功恢复`。
*   **诊断 SOP**：
    1. **使用 GPU-Z 监测 Hotspot（热点）温度**：核心 65℃ 但热点超过 105℃，说明散热器悬空或硅脂干涸，触发了显卡自身的过热保护；
    2. **检查 12V 供电轨压降**：打开 HWiNFO64 观察满载时“GPU 12V Input Voltage”，若跌至 11.4V 以下，说明电源承受不住动态尖峰脉冲，必须更换 ATX 3.0/3.1 电源；
    3. **降频/锁频验证**：使用 MSI Afterburner 将显卡核心频率降 100MHz，显存频率降 200MHz，若掉驱动现象彻底消失，说明该显卡出厂体质虚标或略有老化。

### 3.2 显卡花屏形态判别（硬件损坏 vs 驱动故障）
*   **粉紫色规则棋盘格 / 方块花屏（Space Invaders）**：
    *   **判定**：显存颗粒（VRAM）物理虚焊或显存通道损坏（曾见于初期特定批次美光 GDDR6）。必须通过 BGA 芯片级返厂重植显存。
*   **游戏特定 3D 贴图拉丝 / 三角面飞出**：
    *   **判定**：GPU 核心的某个流处理器单元（SM）在执行特定浮点运算时出错，或当前游戏着色器缓存损坏（在驱动控制面板清理 Shader Cache 即可恢复）。

## 4. 固态硬盘（SSD）隐性病与掉速诊断

### 4.1 冷数据掉速修复流程
*   **诊断工具**：运行 **HD Tune Pro** 对整盘执行一次“基准读取测试”（从 0% 扫至 100%）。
*   **判定特征**：新写入的区块读取曲线高达 5000MB/s，而在存放数月的旧系统/游戏区块处，曲线骤然下坠出现深不见底的“大坑”（速度掉至 20~50MB/s）。
*   **处理方案**：
    1. 使用 **DiskFresh** 软件在 Windows 下执行非破坏性扇区刷新；
    2. 挑选支持“后台自主数据巡检与刷新”的大厂固件原厂固态。

## 5. DPC Latency（延迟中断）与爆音排查全景

*   **测试基准**：运行 **LatencyMon** 15 分钟，若 `Highest measured DPC routine execution time` 突破 1000μs，系统状态栏变为红色。
*   **根治步骤**：
    1. **显卡能耗管理**：NVIDIA 控制面板 -> 管理 3D 设置 -> 电源管理模式 -> 设为 **最高性能优先**；
    2. **网卡节能优化**：设备管理器 -> 网络适配器 -> 禁用 `Energy Efficient Ethernet (EEE)`、`Green Ethernet` 及 `Wake on Magic Packet`；
    3. **主板 C-State**：对于极限音乐制作（DAW）用户，在 BIOS 中将 CPU C-States 锁定在 C1/C0，避免 CPU 频繁切入 C6/C8 唤醒产生的中断开销。
