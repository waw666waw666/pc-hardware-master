# 散热模组、相变片 PTM7950 与鳍片“堵棉花”物理保养指南 (Cooling, Thermal Maintenance & PTM7950 Guide)

本手册专为 AI Agent 诊断和指导 Windows 电脑（尤其是游戏本与高性能工作站）的**突发高温撞墙、风扇狂啸降频、硅脂“抽吸效应”干涸、散热鳍片“堵棉花”灰尘阻塞以及被动散热支架选型**提供硬核物理层排查与维护方案。

## 一、为什么买了半年一年的电脑突然“又热又卡”？

当用户反馈“刚买来打游戏非常丝滑，最近几个月玩十几分钟风扇就起飞、键盘烫手、游戏帧率从两百多断崖跌到几十甚至几帧”时，90% 以上由以下物理散热退化引起：

### 1. 散热鳍片出风口“堵棉花” (Felt Blanket Effect)
- **物理现象**：游戏本的涡轮风扇高速吸风，将空气中的皮屑、猫狗毛发与微尘抽入机身。由于散热铜鳍片（Copper Fins）的缝隙极其狭窄（通常仅 0.2~0.5 毫米），毛发纤维会在**铜鳍片的迎风面死死织成一张致密的“毛毡/棉被”**；
- **致命后果**：从机身外部看风扇拼命在转，但**出风口几乎感觉不到任何热风排出**！热量完全积压在散热铜管内部，CPU 和 GPU 瞬时突破 100°C 和 87°C 的物理温控墙，触发降频断崖卡死；
- **排查方法**：打游戏时用手掌靠近电脑左右两侧及后方出风口，若风扇声音震天响但出风微弱，即为典型的“堵棉花”！

### 2. 传统硅脂的致命克星：抽吸效应 (Pump-Out Effect)
- **原理**：笔记本 CPU / GPU 均为没有均热顶盖的 **裸芯片（Bare Die）**，芯片发热膨胀与冷却收缩的形变极其剧烈；
- 普通导热硅脂（如信越 7921、TF7、MX-4）在经历数十次 40°C~95°C 的冷热循环膨胀挤压后，液态硅油会被彻底**“挤压泵出”**芯片核心区域，核心表面直接出现大面积干涸露铜（Die Exposure），导致局部极速过热。

## 二、材料革命：霍尼韦尔 PTM7950 相变导热片 (终极解法)

联想拯救者、华硕天选、戴尔游匣等现代高端游戏本在出厂时多数已全面转向 **PTM7950 相变导热贴**。

### 1. 相变导热机制
- **常温（<45°C）**：呈固体片状，韧性高，安装裁剪极其方便，绝不导电（零短路风险，相比危险的液态金属具有压倒性安全性）；
- **高温（>45°C）**：物理融化为微流动液态，完全填充芯片纳米级微孔隙，热阻极低；
- **自愈机制**：关机降温后重新凝固为固态，**终生免疫抽吸效应与干涸**，贴一次可稳定服役 3~5 年无需重复更换！

### 2. 选购与换装避坑铁律
1. **厚度选择**：裸 Die 核心**必须且只能选用 0.2mm 厚度**（严禁购买 0.5mm 以上的普通硅胶垫，否则铜管无法压合芯片直接烧穿）；
2. **冷冻撕膜技巧**：PTM7950 常温下极薄且软，贴之前**放进冰箱冷冻室冷冻 5~10 分钟**，硬化后即可极速撕除两侧塑料保护薄膜，平整贴合在核心上。

## 三、物理环境与进风调优 (0 成本降温 5°C~8°C)

很多用户把笔记本平放在软质桌布、床上使用，直接堵死了机身底部的进风栅格。

### 1. 垫高机身底部 (最立竿见影的免费神操作)
- **实验数据**：仅用两个瓶盖或一个折叠支架将笔记本**后脚垫抬高 2~3 厘米**，即可让进风截面积提升 300%！
- **降温效果**：风扇吸风阻力瞬间骤降，CPU/GPU 温度平均**直接立降 4°C ~ 8°C**，噪音明显变小。

### 2. 压风式散热支架选型准则 (红魔 / 飞智 / 联想拯救者)
- 普通抽风式或几块钱的 USB 弱风散热板属于智商税，风量甚至无法吹透底壳；
- 真正有效的降温工具为 **带密封海绵圈的工业级压风式散热底座**（通过大口径离心风扇将机箱外冷风强行压入底部进风格栅，可实现 10°C~18°C 的断崖式降温）。
