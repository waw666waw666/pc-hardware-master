# DPC 延迟、音频爆音与高回报率鼠标外设排障手册 (DPC Latency, Audio & Peripheral Guide)

本手册专为 AI Agent 诊断和解决 Windows 系统中深层次的 **DPC 延迟异常、声卡爆音/杂音、USB 外设休眠顿挫以及高回报率电竞鼠标移动掉帧** 提供排障指南。

---

## 一、DPC 延迟（Deferred Procedure Call Latency）的本质

### 1. 什么是 DPC 延迟？
Windows 处理硬件设备（网卡、显卡、声卡、主板芯片组）请求时，先触发硬中断（ISR），再将耗时任务放入延迟过程调用（DPC）队列供 CPU 处理：
- **正常状态**：所有驱动程序的 DPC 执行时间应在 `100 ~ 500 微秒 (μs)` 以内。
- **异常状态**：如果某个糟糕的驱动程序霸占 CPU 核心超过 `1000 ~ 2000 μs`，系统的实时音视频流就会被强行打断。
- **直观表现**：
  1. 游戏对局中画面出现周期性有规律的“咔嗒”微顿挫；
  2. 耳机或音响中传出“噼啪/爆音/电流音（Audio Cracking/Popping）”；
  3. 鼠标指针突然无规律飘动或短暂失灵。

### 2. 常见引发 DPC 延迟爆表的主谋驱动
| 故障驱动文件名 | 对应硬件设备 | 典型诱因与对策 |
| :--- | :--- | :--- |
| `nvlddmkm.sys` | NVIDIA 显卡驱动 | 显卡动态电源状态频繁在 P-State 之间切换。**对策**：在 NVIDIA 控制面板将电源管理模式设为「最高性能优先」。 |
| `ACPI.sys` | 主板 ACPI 电源控制 | 笔记本电池健康轮询、温控传感器频繁中断。**对策**：插电使用、更新主板 BIOS、关闭多余温控轮询软件。 |
| `ndis.sys` / `wlan*.sys` | 网卡驱动 | Wi-Fi 漫游主动探测信道、网卡节能休眠。**对策**：调低漫游主动性、关闭 SMPS 节能、关闭数据包合并。 |
| `rt640x64.sys` / 声卡驱动 | Realtek 声卡驱动 | 声卡 DAC 芯片自动待机休眠与唤醒。**对策**：关闭声卡驱动音频节能，禁用 Nahimic 等第三方环绕声垃圾插件。 |

## 二、高回报率鼠标（1000Hz / 4000Hz / 8000Hz）移动掉帧真相

### 1. 为什么“我不动鼠标很流畅，一甩鼠标帧率直接暴跌”？
许多电竞玩家使用的是支持 4K 或 8K 回报率的高端电竞鼠标：
- **1000Hz**：每秒向系统报告 1000 次坐标；
- **8000Hz**：每秒向系统报告 8000 次坐标！
- **系统瓶颈**：如果游戏使用的是 Windows 传统的 `WM_INPUT` 或窗口消息循环来获取鼠标位置，CPU 会在 1 秒内被 8000 次硬件中断彻底打爆，Windows 消息队列发生严重拥堵！
- **玩家体验**：站在原地不动帧率 300 帧；一旦快速甩枪拉镜头，帧率瞬间跌到 20~30 帧，严重卡顿。

### 2. 解决方案
1. **游戏内务必开启「纯净输入缓冲区 (RawInputBuffer)」**：
   - 比如《无畏契约》设置 -> 鼠标 -> 开启「纯净输入缓冲区」；
   - 该功能直接越过 Windows 繁重的窗口消息队列，直接从 USB HID 底层缓冲区读取原始鼠标相对位移，彻底消除 4K/8K 鼠标甩枪掉帧。
2. **在鼠标驱动中合理设置回报率**：
   - 如果 CPU 单核性能较为有限（如低压 CPU 或移动端老架构），建议将鼠标回报率设为稳定的 **1000Hz 或 2000Hz**，日常手感无任何区别，但能大幅减轻 CPU 中断负载。

## 三、USB 选择性挂起（USB Selective Suspend）引发的外设休眠顿挫

### 1. 机制与弊端
Windows 为了在笔记本电池模式下省电，默认启用了 USB 选择性挂起功能：
- 当一个 USB 端口在几十毫秒内没有检测到活跃数据流动时，系统会将该 USB 控制器置入低功耗休眠模式；
- 当玩家停止操作 2 秒突然快速拉枪时，USB 端口需要经历一个“从挂起到唤醒”的毫秒级电压提升与枚举过程；
- **直观表现**：开火第一枪感觉准星卡顿了一下，或者蓝牙/无线接收器出现间歇性丢帧。

### 2. 彻底禁用对策
```powershell
# 禁用当前活动电源方案的交流电 USB 选择性挂起
powercfg /setacvalueindex SCHEME_CURRENT 2a737441-1930-4402-8d77-b2bebba4d5a0 48e6b7a6-50ba-4730-a5ce-72c8189cc5c2 0
powercfg /setactive SCHEME_CURRENT
```
