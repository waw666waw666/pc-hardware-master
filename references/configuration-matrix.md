## 2. 移动端笔记本电脑选型基准表

*   **轻薄办公本选型红线**：
    - **屏幕**：必须 100% sRGB / DCI-P3 广色域，DC 调光或高频 PWM 无频闪；
    - **接口**：至少配备 1 个全功能 Type-C（支持 PD 100W 快充与 DP 输出）；
    - **内存**：板载内存必须 32GB 起步（因为无法更换升级）。
*   **游戏本选型红线**：
    - **显卡功耗**：RTX 4060 必须为 140W 满血版（拒绝 45W 阉割残血版）；
    - **显示直连**：必须支持 **独显直连 (Mux Switch) 或 Advanced Optimus**；
    - **散热模组**：观察出风口数量（双出风口 vs 四出风口）与热管粗细（必须有贯穿均热板或 10mm 主热管）。

## 3. 迷你主机与小型设备推荐基准

*   **千元级软路由 / 极简办公**：Intel N100 / N305 平台（单核够用、四网口/双 2.5G 网口、功耗仅 6~15W）。
*   **三千元级全能高能效桌面迷你主机**：AMD Ryzen 7 8845HS / 7840HS 准系统（配双 SO-DIMM DDR5 5600 内存 + 1TB 原厂 PCIe 4.0 固态，集成 Radeon 780M 强劲核显，通吃 1080P 网游与办公）。

## 4. 家用服务器 (Homelab / NAS) 推荐矩阵

*   **低功耗四盘位方案（预算 1500~2500 元）**：
    - **CPU**：Intel i3-12100 / 12100T（带 UHD 730 核显，支持多路 4K Plex/Jellyfin 硬件转码）；
    - **主板**：拓普龙/畅网 6 盘位 ITX NAS 专用主板（原生集成双 2.5G 网卡与多个 SATA 接口）；
    - **内存**：16GB / 32GB DDR4 3200 ECC/Non-ECC；
    - **硬盘**：希捷银河 Exos 16TB × 2 (CMR 企业氦气盘，RAID 1 / ZFS Mirror)。
