# 工业级硬件验机、诊断与基准压力测试标准 (Tools & Benchmarks)

本文档制定了从整机装配完成到出厂验收的完整工业级软硬件测试工具链与合格性判定标准。

---

## 1. 核心诊断与遥测工具链清单

| 软件工具 | 核心功能与监控参数 | 推荐使用阶段 |
| :--- | :--- | :--- |
| **HWiNFO64** | 芯片底层遥测（核心电压 VID、VRM 温度、GPU Hotspot、显存结温、**WHEA 错误计数器**） | 全程监控 |
| **GPU-Z** | 显卡芯片规格、PCIe 物理总线协商测试、微码与显存颗粒厂商识别 | 验机与接口测试 |
| **CPU-Z** | 处理器架构、指令集、内存双通道与第一时序、主板 BIOS 版本查看 | 初始硬件核验 |
| **CrystalDiskInfo** | 硬盘 S.M.A.R.T. 健康度、通电时间、通电次数、05/0E 重映射扇区报警 | 硬盘验新/防翻新 |
| **LatencyMon** | DPC / ISR 中断延迟分析，精准定位导致音频爆音与微卡顿的驱动文件名 | 系统调谐与音视频排查 |
| **TestMem5 (TM5)** | 搭配 `anta777 Extreme1` / `Absolut` 配置，抓取内存极端数据位翻转 | 内存超频与 XMP 压测 |
| **Display Driver Uninstaller (DDU)** | Windows 安全模式下彻底清除显卡驱动及其注册表残留、音频设备上下文 | 显卡驱动升级与掉驱动修复 |
| **CoreCycler** | 基于 Prime95 单线程逐核循环压测，排查 AMD PBO2 核心体质欠压黑屏 | CPU 曲线优化调谐 |

## 2. 稳定性烤机与合格判定标准

### 2.1 内存稳定性：TestMem5 (TM5) 压测
*   **测试配置**：加载 `anta777 Extreme1` 或 `Absolut` 脚本配置文件。
*   **合格标准**：连续运行 **3 轮（Cycle）以上，Error 计数器保持为 0**。
*   **失败表象与定位**：
    - 若在第 1 轮就报错：第一主时序过紧、电压不足（VDD/VDDQ 需要加压 0.03V）；
    - 若在跑了 40 分钟后（第 2~3 轮）突然跳错：**内存温度积聚突破 50℃~55℃ 导致电荷翻转**，必须加装风扇或适当放松 `tREFI`。

### 2.2 CPU 与供电极限：AIDA64 单烤 FPU
*   **设置方法**：打开 AIDA64 -> 工具 -> 系统稳定性测试 -> **仅勾选 `Stress FPU`**（单烤 AVX/FPU 浮点单元，负载远高于 CPU 综合测试）。
*   **合格标准**：
    1. 连续烤机 **30 分钟不降频、无红字报警、无蓝屏**；
    2. CPU 温度维持在 TJMax 保护阈值以下（7800X3D < 85℃，14700K < 95℃）；
    3. 主板 VRM 供电温度低于 90℃（杜绝 VRM Thermal Throttling）。

### 2.3 显卡稳定性：3DMark Time Spy / Steel Nomad 压力测试
*   **设置方法**：运行 3DMark 压力测试（20 轮连续渲染循环）。
*   **合格标准**：
    1. **稳定性帧率一致性（Frame Rate Stability）达到 97.0% 以上**；
    2. 核心温度低于 75℃，**Hotspot 热点温度低于 90℃**（温差小于 15℃）；
    3. 全程无花屏、无绿点闪烁、无 TDR 驱动崩溃。

### 2.4 终极整机双烤（电源与机箱风道终极严刑）
*   **测试方法**：同时开启 **AIDA64 Stress FPU + FurMark（甜甜圈，选 4K 分辨率 8x MSAA）**。
*   **监控重点**：
    1. 观察整机功耗是否达到平台最大功耗设计；
    2. 持续 20 分钟电源不触发 OCP/OPP 断电保护关机；
    3. 观察 HWiNFO64 底部的 **Windows Hardware Errors (WHEA)** 计数器是否始终为 0。若出现任何一条错误，说明硬件处于亚稳定状态。
