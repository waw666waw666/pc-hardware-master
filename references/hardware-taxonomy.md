# 全品类计算机形态与硬件体系全景图谱 (Hardware Taxonomy)

本文档系统拆解现代计算机全部主流形态的技术特征、核心选型指标、散热架构及特有工程雷区。

---

## 1. 桌面台式机 (Desktop DIY)

### 1.1 架构与形态分类
*   **全塔 / 中塔 (ATX / E-ATX)**：空间充裕、散热风道极佳、扩展性强，支持 360/420 水冷及 4 槽厚度旗舰长卡，适合极限超频、多盘位、工作站与高端单卡/双卡平台。
*   **紧凑型中塔 (M-ATX)**：当前性价比最高、流通量最大的主流形态。兼顾双 M.2 扩展、4 内存插槽与良好散热，机箱体积适中（约 25~35L）。
*   **极限小钢炮 (Mini-ITX / SFF < 20L)**：
    *   **架构特征**：单 PCIe 插槽、双内存槽、高度集成的供电与散热、SFX/SFX-L 电源。
    *   **工程难点**：
        1. **PCIe 延长线陷阱**：海景房/背靠背结构依赖 PCIe 延长线，劣质线缆极易引发高频信号衰减、自动协商降级为 PCIe 3.0 或频繁弹出 WHEA 17 硬件纠错。
        2. **风道死角与热堆积**：内部空间狭小，负压差容易形成湍流和热死区，需优先保证 CPU 与显卡独立直吸冷风。

### 1.2 核心选型准则
*   **CPU 与主板供电匹配**：看懂 DrMOS 单相持续供电能力与散热片厚度，严禁“小马拉大车”引发 VRM 过热降频。
*   **电源余量与规范**：必须符合 ATX 3.0/3.1 规范，额定功率满足整机满载 1.5 倍以上冗余以吸收 200% 瞬时脉冲。

## 2. 移动笔记本电脑 (Laptops & Mobile)

### 2.1 分类与定位
*   **轻薄本 (Ultrabook, < 1.4kg)**：以续航、便携和低功耗为核心，搭载低压/标压核显 CPU（如 Intel Core Ultra、AMD Ryzen 7000/8000/AI 300 系列）。
*   **全能本 (Creator Laptop, 1.6~2.0kg)**：兼顾便携与图形创作，搭载中瓦数 CPU + 中端独显（如 RTX 4050/4060，60~90W TGP），屏幕通常为高分辨率高色准 OLED 或 Mini-LED。
*   **游戏本 (Gaming Laptop, 2.2~3.0kg)**：追求满血性能释放，双风扇多热管/大面积均热板散热，搭载高功耗 CPU + 满血独显（140W~175W TGP）。

### 2.2 移动端核心技术与雷区
*   **显示链路模式**：
    *   **混合输出 (Optimus / MSHybrid)**：独显帧经由核显显存中转输出，延迟增加 5~15ms，高刷电竞游戏掉帧 15%~25%。
    *   **独显直连 (Mux Switch)**：硬件物理继电器切换，切断核显，内屏直通独显输出。
    *   **Advanced Optimus (高级热切换)**：无需重启即可根据当前全屏程序自动无缝切换直连与核显通道。
*   **功耗墙机制 (TGP & Dynamic Boost)**：
    *   厂商标称的“满血”通常包含 Dynamic Boost 动态分配（如 115W 基准 + 25W 动态借调）。若 CPU 负载极高占满功耗池，显卡会被强行压制在基准功耗以下，导致游戏瞬间掉频。
*   **导热介质维护与“液金偏流”**：
    *   液态金属在长期颠簸与高温下易发生“抽干”（镓元素向铜底渗透合金化），导致单核温差超 30℃。推荐使用霍尼韦尔 PTM7950 相变导热片进行根治。

## 3. 迷你主机与掌上电脑 (Mini PC & NUC)

### 3.1 架构与应用场景
*   **1L 容积桌面迷你主机 (如 零刻、MINISFORUM、Intel NUC 系列)**：
    *   **硬件方案**：多采用移动端标压 APU（如 R7 7840HS、R7 8845HS、Ryzen AI 9 HX 370），集成强大的 RDNA3 / 3.5 核显（Radeon 780M / 890M），支持 65W 激进释放。
    *   **适用场景**：极简桌面办公、4K 影音、中轻度网游（LOL/CS2）、软路由与移动便携开发机。
*   **扩展性考量**：
    *   必须关注内存是否为可插拔 SO-DIMM（板载 LPDDR5 虽频率高但无法升级）；
    *   关注是否具备全功能 USB4 / 雷电 4 接口（支持 40Gbps 带宽外接显卡拓展坞 eGPU 或一线通便携显示器）。

## 4. 家用服务器与私有存储 (Homelab / NAS / AIO)

### 4.1 硬件选型核心法则
*   **低待机功耗 (Low Idle Power)**：
    *   7×24 小时开机运行，整机待机功耗比满载功耗更重要。
    *   **Intel 消费级平台优势**：配合 UHD 核显及优秀的 C-State（C8/C10 深度休眠），待机功耗可压制至 10~15W 以内；AMD 桌面平台由于 I/O Die 功耗固定，待机功耗通常偏高（25~35W+）。
*   **硬盘选型生死线**：
    *   **坚决杜绝 SMR（瓦片式磁记录）硬盘**：SMR 在数据重写时会触发整磁道重叠擦写，在 ZFS 或 RAID 阵列重建（Resilver）时极易发生极速掉速至几 KB/s 甚至直接掉盘损坏阵列。
    *   **必须选用 CMR / PMR（传统垂直磁记录）原生企业级/NAS 专用盘**（如西部数据红盘 Plus、希捷酷狼、西数 HC320/HC550、希捷银河 Exos）。
    *   **二手企业盘鉴别**：警惕淘宝低价“清零盘”（通过特殊指令刷写 SMART 日志清零通电时间和坏道重映射表），需查看出厂年份及完整慢速扇区表面扫描。
*   **ECC 内存的重要性**：
    *   作为文件服务器或运行 ZFS 存储池时，未纠正的内存位翻转（Bit Flip）会把错误数据静默写入硬盘校验块中造成数据静默损坏。在关键数据 Homelab 中优先考虑带 ECC 支持的平台。

## 5. 掌上游戏设备 (Handheld Gaming Devices)

### 5.1 架构特征 (ROG Ally / Legion Go / Steam Deck)
*   **定制 APU 架构**：以 AMD Van Gogh (Steam Deck) 与 AMD Z1 Extreme (ROG Ally) 为代表，在 9W~30W 极窄功耗窗口内动态权衡 CPU 与 GPU 算力。
*   **调优要点**：
    1. **显存共享划分 (VRAM Allocation)**：默认通常只分配 2GB~4GB 显存，进入 BIOS 将显存划分为 **6GB 或 Auto 动态调节**，既防止大型 3A 爆显存闪退，又给系统主运存保留足够空间。
    2. **TDP 甜蜜点控制**：手持设备能效比最高区间通常在 15W~18W，盲目开启 30W 暴力模式会带来风扇狂啸与电量雪崩，而实际帧率提升仅 10%~15%。

## 6. 工作站与二手服务器 (Workstations & Enterprise Repurposing)

### 6.1 捡垃圾（洋垃圾）与多路服务器改造
*   **Intel Xeon E5 v3/v4 架构**：
    *   利用“鸡血补丁”（EFI 驱动注入）破解锁定全核最大睿频，配合低廉的 DDR4 REG ECC 服务器内存条，在低预算下构建数十核心并行编译/虚拟化平台。
    *   **缺点**：单核 IPC 极其老旧、主频低、缺乏现代 AVX-512/AVX2 新扩展指令集、主板多为小厂山寨改版，故障率与电气杂讯高，**绝对不适合电竞高刷游戏**。
*   **AMD EPYC（霄龙）与 Threadripper（线程撕裂者）**：
    *   现代专业工作站的绝对王者，单 CPU 提供多达 128 条 PCIe 直出通道与 8 通道 / 12 通道 DDR5 内存带宽，适合多张专业深度学习 GPU 并行计算与巨型物理流体仿真。
