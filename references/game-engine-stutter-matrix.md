# 主流游戏引擎特征与专属掉帧排查手册 (Game Engine Stutter & Optimization Matrix)

本手册专为 AI Agent 针对玩家运行不同游戏引擎（**虚幻引擎 UE4/UE5、Source 2、Unity、各类 3A 原生引擎**）时，精准匹配引擎底层架构特性并实施针对性调优。

---

## 一、虚幻引擎 (Unreal Engine 4 & 5)
> 代表作品：《无畏契约》、《绝地求生 (PUBG)》、《黑神话：悟空》、《堡垒之夜》

### 1. 虚幻引擎的典型卡顿特征
- **初次遇敌/初次进图卡顿**：几乎 100% 由 **着色器编译（PSO Caching）** 引起。
  - 对策：清理本地历史臃肿的 DXCache，进游戏大厅等待 2 分钟让游戏在后台完成预编译。
- **烟雾弹与大招混战卡顿**：
  - 虚幻引擎的 **阴影（Shadow Quality）** 计算极为消耗 CPU Draw Calls；
  - 竞技游戏（瓦罗兰特、PUBG）**务必将阴影质量拉到「低」**，1% Low 帧率通常直接翻倍。

### 2. 启动参数与图形 API 选择
- 很多虚幻 4 游戏在老机器上运行 DX12 容易掉帧，可以在 Steam / 启动器中添加 `-dx11` 强制回退到稳定的 DirectX 11 模式；而在现代支持 rBAR 的机器上，DX12 配合 Reflex 表现更佳。

## 二、Source 2 引擎
> 代表作品：《Counter-Strike 2 (CS2)》、《Dota 2》

### 1. CS2 极度吃 CPU 单核主频与 L3 缓存
- CS2 对显卡要求适中，但对 CPU 的单核性能和三级缓存（如 AMD X3D）极其敏感。
- **调度避坑**：Intel 12/13/14 代大小核处理器，必须开启 Windows 游戏模式，确保主物理模拟与 Sub-tick 线程死锁在 P-Core 上。

### 2. CS2 “黄金防撕裂与最低延迟组合拳” (Blur Busters 权威标准)
1. **NVIDIA 控制面板**：
   - 垂直同步 (V-Sync) -> **开启**；
   - G-Sync / G-Sync Compatible -> **开启**；
   - 低延时模式 -> **超高 (Ultra)**；
2. **CS2 游戏内设置**：
   - 垂直同步 -> **关闭**；
   - NVIDIA Reflex -> **开启 + BOOST**；
3. **效果**：Reflex 会自动将游戏帧率锁在显示器刷新率下方 3~4 帧（如 165Hz 屏幕自动锁 158 FPS），**彻底消除画面撕裂、彻底消除传统垂直同步带来的输入延迟，且拥有完美的帧生成时间**。

## 三、Unity 引擎
> 代表作品：《原神》、《崩坏：星穹铁道》、《永劫无间》、《Rust》

### 1. 垃圾回收机制（Garbage Collection, GC）卡顿
- Unity 游戏多采用 C# / Mono 虚拟机。当内存中临时分配的对象达到阈值时，GC 收集器会强行暂停游戏线程 20~80ms 进行内存垃圾回收；
- **直观表现**：每隔几十秒有规律地顿一下。
- **对策**：
  - 绝对不能在后台开 `Mem Reduct` 等内存压缩软件（会导致 GC 更加频繁且加剧硬盘缺页）；
  - 保证系统物理内存剩余至少 4GB 以上供 Unity 堆内存扩展。

## 四、Windows 11 窗口化游戏优化 (Optimizations for Windowed Games)

现代 Windows 11 引入了全新的窗口化演示模型（Flip Model）：
- 开启后，即使用户在“无边框窗口化（Borderless）”模式下玩游戏，也能获得类似“独占全屏（Fullscreen Exclusive）”的极低延迟与 Auto HDR / VRR 刷新率同步；
- **排查与开启**：
  Windows 设置 -> 系统 -> 屏幕 -> 图形 -> 默认图形设置 -> **开启「针对窗口化游戏的优化」**。
